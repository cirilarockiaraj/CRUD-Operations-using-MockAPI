
# User CRUD Application

A simple User CRUD (Create, Read, Update, Delete) web application built using HTML, CSS, JavaScript, and MockAPI.io. This application allows users to manage user information through a responsive and interactive interface.

## Features

- Create new users.
- View all users.
- Update existing user details.
- Delete users.
- Manage user information using MockAPI.io.
- Perform CRUD operations using JavaScript Fetch API.
- Responsive user interface.
- Form validation for user inputs.

## User Fields

- Name
- Email
- Phone Number

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- MockAPI.io (REST API)

## CRUD Operations

| Operation | HTTP Method | Description |
|-----------|-------------|-------------|
| Create | POST | Add a new user |
| Read | GET | Fetch and display users |
| Update | PUT | Update existing user details |
| Delete | DELETE | Remove a user |

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/cirilarockiaraj/CRUD-Operations-using-MockAPI
   ```

2. Navigate to the project directory.

3. Configure your MockAPI endpoint in the JavaScript file.

4. Open `index.html` in your browser.

   Alternatively, use the VS Code Live Server extension.
